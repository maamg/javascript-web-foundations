# JavaScript and Web Foundations

This repository groups my JavaScript and front-end learning by concept. It is a record of progression from language syntax to small browser-based interfaces.

## Sections

| Section | Evidence |
| --- | --- |
| ES6 fundamentals | let/const, template literals, arrow functions, spread syntax, classes and inheritance |
| JavaScript concepts | Scope, closures, equality, null/undefined, array methods and object properties |
| Small assignments | Functions for conversion, budgets, hotel cost and simple problem solving |
| Browser applications | Selected interfaces remain in their original repositories, including weather, meal search, shopping-cart and grocery exercises |

The application repositories are intentionally kept separate so their original URLs and histories remain available. This repository is the easier academic overview; it is not a claim that the browser exercises are production applications.

## Attribution and status

Exercises, tutorials, personal adaptations and unfinished experiments are labelled in their individual notes. The original repositories remain listed in the account project directory.
